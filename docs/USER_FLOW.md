# PadungGo User Flow

## Main Journey

Open App → Select Origin → Select Destination → Validate Locations →
Request Journey Options → Review Alternatives → Select Route → View
Instructions → Request Return Trip

## Origin Selection

Supported methods: - GPS permission - Manual search - Map pin -
Predefined locations

## Route Results

Display: - Route option - Vehicle information - Boarding location -
Transfer instructions - Fare estimate - Walking time - Waiting time when
available - Riding time

## Error States

Handle: - GPS denied - Unsupported locations - Missing route data -
Network failure - No verified route found

## Accessibility

-   Mobile-first layout
-   Clear text
-   Avoid relying only on color
-   Simple commuter language
