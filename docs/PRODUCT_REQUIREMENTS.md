# PadungGo Product Requirements

## Overview

PadungGo is an open-source public transportation journey planner for
selected verified routes across Cebu City, Mandaue City, and Lapu-Lapu
City.

## Problem

Commuters often know their destination but lack reliable information
about what vehicle to ride, where to board, fares, travel time,
transfers, and return journeys.

## Target Users

-   Students
-   Workers
-   Tourists
-   New residents
-   Occasional commuters

## MVP Objectives

-   Provide trustworthy public transport journey suggestions.
-   Prioritize route accuracy over route quantity.
-   Explain fare and travel-time assumptions.
-   Provide independent return-trip suggestions.

## Functional Requirements

-   Origin and destination selection:
    -   GPS
    -   Search
    -   Map selection
    -   Curated locations
-   Direct and verified one-transfer routes.
-   Fare estimates.
-   Walking, waiting, and riding breakdown.
-   Route source and verification information.

## Non-Goals

-   Live vehicle tracking.
-   Nationwide coverage.
-   User accounts.
-   Payment systems.
-   Storing personal GPS history.

## Security and Privacy

-   Protect secrets and credentials.
-   Avoid storing unnecessary location history.
-   Validate all user inputs.
-   Restrict administrative access.

## Success Criteria

A commuter can select locations and receive understandable,
evidence-backed journey options.
