Import places from OpenStreetMap

Downloads named schools, hospitals, malls, landmarks, attractions, offices and terminals inside Cebu City, Mandaue and Lapu-Lapu from OpenStreetMap (one request to the free Overpass server; no key or cost) and makes them searchable, including by acronym.

  • Places are stored as documented locations. They are not route or stop evidence.
  • Running it again updates the same records; it never changes hand-made or GTFS locations, routes or fares.
  • Data © OpenStreetMap contributors, ODbL 1.0.
  • It can take one to three minutes. Press the button once.
