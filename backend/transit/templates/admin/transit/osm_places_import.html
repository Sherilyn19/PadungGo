Import places from OpenStreetMap

Makes named schools, hospitals, malls, landmarks, attractions, offices and terminals searchable (including by acronym) for Cebu City, Mandaue and Lapu-Lapu. Free; no key.

  • Places are stored as documented locations. They are not route or stop evidence.
  • Running it again updates the same places. It never changes your own locations, GTFS stops, routes, fares or availability flags.
  • Data © OpenStreetMap contributors, ODbL 1.0.
