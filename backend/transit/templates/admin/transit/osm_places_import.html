Import places from OpenStreetMap

Makes named schools, hospitals, malls, landmarks, attractions, offices and terminals searchable (including by acronym) for Cebu City, Mandaue and Lapu-Lapu. Free; no key.

  • Places are stored as documented locations. They are not route or stop evidence.
  • Running it again updates the same places. It never changes your own locations, GTFS stops, routes, fares or availability flags.
  • Data © OpenStreetMap contributors, ODbL 1.0.

Option 1: download from OpenStreetMap

Option 2: if option 1 keeps failing

Download the data on your own computer, then upload the file here. A web browser cannot do the download (the OpenStreetMap server refuses browsers), so use Windows PowerShell (Windows 10 or 11):

  1. Open PowerShell and run cd $HOME\Downloads.
  2. Copy and paste a city's two-line command below, press Enter, and wait up to two minutes. If it shows an error such as 502 or 504, just run it again.
  3. It saves a .json file in that folder. Choose it below and press the button.
